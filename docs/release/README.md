# 候选发布门禁

目标候选版本：`v0.4.0`。

## 当前结论

本地安装、测试、类型检查、构建和体积预算可以通过，但当前静态产物**不得对外发布**。原因记录在 `asset-inventory.json`：发行包会包含缺少明确再分发证据的 GUO、Mixamo、UE Mannequin 和基准全景图资产。

## 必须通过的门禁

1. `npm run verify`：安全审计、测试、类型检查、构建和体积预算。
2. `npm run release:check`：全部发行资产状态必须是 `approved-for-redistribution`。
3. Fresh clone 重复执行上述命令。
4. 浏览器完成旧工程恢复、镜头编辑、截图/视频入口和 iframe v1 契约验收。
5. 明确目标仓库和环境后，才允许启用或修改 Pages/Release 工作流。

## 解除资产阻断

- 为每项资产保存可追溯的作者、原始地址、许可证文本或法务批准编号。
- 核对许可证是否允许把原始模型/动作文件随产品独立再分发，而不仅是允许渲染或创作衍生作品。
- 只有证据完成后才把对应状态改为 `approved-for-redistribution`。

## 回滚

若某项资产无法取得批准，应从候选发行包中排除该目录，并确认应用在缺少可选资产时仍显示不可用状态；不得删除开发者本地原始素材来代替发行过滤。
